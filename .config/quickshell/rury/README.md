# SigniorAtif

A personal Quickshell desktop for Hyprland. Run it with `qs -c rury`.

## Origin and license

This is a modified version of [end-4/dots-hyprland](https://github.com/end-4/dots-hyprland)
("illogical-impulse"), forked from commit `2f0c8bf` (2026-09-14) and changed
substantially since. Copyright for the original work remains with end-4 and the
upstream contributors.

Modifications by Atif Ahmed, 2026: the shell was renamed to `rury` internally and
SigniorAtif in its interface; the background, lock and parallax animations were
reworked; keybinds and window rules were ported from a previous Fedora setup.
